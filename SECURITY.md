# Security

Security fixes apply to the current `main` branch. These projects are educational
or community software; review their documented limitations before use.

Report a suspected credential or privacy exposure privately through
[GitHub vulnerability reporting](https://github.com/Achilleus-1/memory-cache-simulator/security/advisories/new).
Include the affected file/revision, impact, and reproduction steps. Do not paste
live credentials or personal records into public issues or pull requests.

If a real credential is exposed, revoke or rotate it immediately. Removing a file
from the current branch does not remove copies in Git history or existing clones.
Repository checks catch common credential formats and local paths; manual review
is still required for data and formats they cannot recognize.
